# W12 - Climate Risk, Extreme Heat, Water Stress, And Resilient Agriculture Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**Climate Risk**, **Hazard**, **Exposure**, **Vulnerability**, **Extreme Heat**, **Heat Stress**, **Water Stress**, **Drought**, **Flood**, **Adaptation**, **Mitigation**, **Early-Warning System**, **Climate Service**, **Resilience**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **Climate Risk** | 气候风险 | 气候变化或极端天气对系统造成损害的可能性。 |
| **Hazard** | 危害 | 可能造成破坏的气候或环境事件。 |
| **Exposure** | 暴露度 | 人、作物或设施是否处在危险影响范围内。 |
| **Vulnerability** | 脆弱性 | 系统受到危害时容易受损的程度。 |
| **Extreme Heat** | 极端高温 | 明显高于正常水平并可能造成健康或生产风险的热天气。 |
| **Heat Stress** | 热应激 | 人、动物或植物因高温而承受的生理压力。 |
| **Water Stress** | 水压力 | 可用水量不足以满足需求的情况。 |
| **Drought** | 干旱 | 长时间缺少降水或水分的状态。 |
| **Flood** | 洪水 | 水量过多并淹没土地、道路或设施的事件。 |
| **Adaptation** | 适应 | 调整系统以减少气候风险造成的伤害。 |
| **Mitigation** | 减缓 | 减少温室气体排放或增强吸收来减缓气候变化。 |
| **Early-Warning System** | 预警系统 | 提前发现风险并发出行动提醒的系统。 |
| **Climate Service** | 气候服务 | 把气象和气候信息转化为可用决策支持的服务。 |
| **Resilience** | 韧性 | 系统在冲击中继续运作或恢复的能力。 |

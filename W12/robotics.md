# W12 Robotics - Climate Risk, Extreme Heat, Water Stress, And Resilient Agriculture

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
Climate resilience missions can become:

```text
heat alert -> robot moves shade marker
water stress -> robot delivers water token
storm warning -> robot moves food to safe storage
cold chain risk -> robot checks temperature station
```

Robots can also gather data after a shock:

- inspect damage,
- check sensors,
- move emergency supplies,
- sort safe and unsafe items.

## Build And Programming Tasks
1. Draw a chain from heat wave to meal price.
2. Choose one point where an early-warning system could help.
3. Design a robot mission for drought, heat, flood, or storage failure.
4. Add one backup plan if the robot fails.
5. Explain the difference between adaptation and mitigation.

# W11 - Food Loss, Food Waste, Circular Economy, And Recovery

## Student Documents

## Weekly Question
Why do people waste food while others are hungry, and what can systems do about it?

## Suggested Learning Order
1. Read `science.md`.
2. Discuss the core terms and past-present-future context.
3. Complete the work in `robotics.md`.
4. Use the videos below for classroom viewing or home extension.

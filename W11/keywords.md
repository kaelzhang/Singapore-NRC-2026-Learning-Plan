# W11 - Food Loss, Food Waste, Circular Economy, And Recovery Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**Food Loss**, **Food Waste**, **Circular Economy**, **Upcycling**, **Food Rescue**, **Composting**, **Anaerobic Digestion**, **Waste Hierarchy**, **Contamination**, **Methane**, **Shelf Life**, **Surplus**, **By-Product**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **Food Loss** | 食物损失 | 食物在收获、储存、加工或运输中进入消费前损失。 |
| **Food Waste** | 食物浪费 | 零售、餐饮或家庭阶段本可食用的食物被丢弃。 |
| **Circular Economy** | 循环经济 | 尽量保持资源价值并减少废弃的经济模式。 |
| **Upcycling** | 升级再利用 | 把副产品或剩余物变成更有价值的新产品。 |
| **Food Rescue** | 食物救援 | 把安全可食用的剩余食物及时转给需要的人。 |
| **Composting** | 堆肥 | 把有机废弃物分解成可改善土壤的材料。 |
| **Anaerobic Digestion** | 厌氧消化 | 在无氧环境中分解有机物并产生沼气等资源。 |
| **Waste Hierarchy** | 废弃物层级 | 从预防、再分配、再利用到最终处置的优先顺序。 |
| **Contamination** | 污染 | 食物或材料混入不安全或不适合的物质。 |
| **Methane** | 甲烷 | 有机物在缺氧条件下分解可能产生的强效温室气体。 |
| **Shelf Life** | 保质期 | 食物在合适条件下保持安全和质量的时间。 |
| **Surplus** | 剩余 | 超过当前需求但可能仍有价值的食物或材料。 |
| **By-Product** | 副产品 | 主要生产过程之外产生但仍可能有用途的材料。 |

# W11 Robotics - Food Loss, Food Waste, Circular Economy, And Recovery

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
Waste and circularity missions can become:

```text
detect item -> classify -> move to correct zone -> record count
```

Examples:

- edible surplus token goes to rescue zone,
- spoiled item goes to compost zone,
- packaging goes to recycling zone,
- cold item goes back to storage.

## Build And Programming Tasks
1. Track one meal and list possible waste points.
2. Sort five example items into edible, compost, recycle, or landfill.
3. Design a robot that sorts two types of objects.
4. Write one rule that prevents waste before it happens.
5. Explain why composting is useful but not the first choice for edible food.

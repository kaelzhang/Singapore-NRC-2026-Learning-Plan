# W05 Robotics - Plant Growth Science: Light, Water, Soil, And Nutrients

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
A farm robot might not "understand" biology, but it can measure and act:

- color sensor: detect coloured plant markers or zones,
- moisture sensor: check whether water is low,
- camera: notice leaf colour or size,
- motor: move trays or open covers,
- light matrix: show plant status,
- pump: deliver water in a model system.

NRC translation:

```text
Plant needs stable water -> robot delivers water token to the greenhouse
Plant needs useful light -> robot activates or marks a lighting station
Plant stress must be noticed -> robot visits sensor zones in order
```

## Build And Programming Tasks
1. Draw a plant and label light, carbon dioxide, water, nutrients, roots, and leaves.
2. Write photosynthesis as a simple arrow equation.
3. Choose one plant need and design a robot action to support it.
4. Identify one tradeoff. Example: LEDs help control light but use electricity.
5. Build a mini "sensor checklist" for a greenhouse robot.

# W01 Robotics - Mission Meals And The Whole Food System

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
This week, do not design the final robot yet. Make a translation map:

```text
Food system problem -> NRC mission idea -> Robot action -> Sensor or mechanism
```

Example:

```text
Fresh food spoils if it waits too long
-> Move food quickly to a cold storage area
-> Robot delivers a crate to a marked zone
-> Color sensor finds the zone, pusher releases the crate
```

# W01 - Mission Meals And The Whole Food System Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**Food System**, **Food Security**, **Availability**, **Access**, **Utilization**, **Stability**, **Food Supply Chain**, **Resilience**, **Bottleneck**, **Feedback Loop**, **Shock**, **Tradeoff**, **Mission Abstraction**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **Food System** | 食物系统 | 食物从生产、运输、储存、加工、食用到废弃处理的完整网络。 |
| **Food Security** | 粮食安全 | 人们能够持续获得足够、安全、有营养的食物。 |
| **Availability** | 可获得量 | 一个地方实际存在多少食物，取决于生产、进口、储备和储存。 |
| **Access** | 获取能力 | 人们是否有钱、交通、时间和权利来得到食物。 |
| **Utilization** | 利用与营养吸收 | 食物是否安全、营养合适，并能被身体正确使用。 |
| **Stability** | 稳定性 | 食物供应和获取是否能在冲击发生时继续保持。 |
| **Food Supply Chain** | 食品供应链 | 食物从生产者到消费者之间经过的一连串环节。 |
| **Resilience** | 韧性 | 系统遇到问题后仍能继续运行或快速恢复的能力。 |
| **Bottleneck** | 瓶颈 | 限制整个系统速度或能力的薄弱环节。 |
| **Feedback Loop** | 反馈回路 | 系统根据结果或数据调整下一步行动的循环。 |
| **Shock** | 冲击 | 突然破坏系统正常运行的事件，例如洪水、热浪或运输中断。 |
| **Tradeoff** | 取舍 | 改善一个目标时可能让另一个目标变难的情况。 |
| **Mission Abstraction** | 任务抽象 | 把真实世界问题简化成机器人可以模拟的小任务。 |

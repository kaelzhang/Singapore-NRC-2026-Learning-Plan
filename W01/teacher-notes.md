# W01 Teacher Notes

## Aim
Students should leave with a whole-system map, not a list of isolated technologies.

## Pacing
- 10 min: Ask students to name everything needed for one familiar meal.
- 25 min: Read the student lesson and build a class food-system map.
- 25 min: Team mapping activity.
- 20 min: Translate one food-system issue into a robot action.
- 10 min: Vocabulary check.

## Misconceptions To Watch
- "Food security means only growing more food." Correct this by using the four dimensions: availability, access, utilization, stability.
- "Robots solve the whole problem." Push students to define one small robot job.
- "Mission Meals is only about farms." Include logistics, storage, safety, waste, and tools.

## NRC Link
Use this week to introduce the idea that every robot action should have a real-world explanation. This will help with Open Category presentations and Regular Category design thinking.

## Evidence Of Learning
Each team should produce a one-page map with:

- a meal,
- at least six system parts,
- one weak point,
- one possible robot task,
- one vocabulary word used correctly.

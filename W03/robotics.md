# W03 Robotics - Agriculture From Domestication To The Green Revolution

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
Your robot is part of a long tool history:

```text
hand tool -> animal power -> machine -> sensor-guided machine -> autonomous robot
```

Ask what your robot controls:

- water,
- movement,
- timing,
- labour,
- sorting,
- information,
- object handling.

## Build And Programming Tasks
1. Make a timeline with at least six agriculture changes.
2. For each change, write "problem solved" and "possible tradeoff."
3. Pick one historical tool and design a robot version of its job.
4. Explain how a future robot could help without harming soil, water, or people.

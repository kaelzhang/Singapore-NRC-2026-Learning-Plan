# W03 - Agriculture From Domestication To The Green Revolution Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**Agriculture**, **Domestication**, **Domestication Syndrome**, **Irrigation**, **Yield**, **Productivity**, **Staple Crop**, **Green Revolution**, **Semi-Dwarf Variety**, **Fertilizer**, **Mechanization**, **Monoculture**, **Biodiversity**, **Tradeoff**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **Agriculture** | 农业 | 人类有计划地种植植物和饲养动物来生产食物。 |
| **Domestication** | 驯化 | 人类长期选择有用性状，使野生动植物逐渐适合人类使用。 |
| **Domestication Syndrome** | 驯化综合征 | 被驯化物种常见的一组变化，例如种子更大或更不易脱落。 |
| **Irrigation** | 灌溉 | 把水送到农田或植物根部，帮助作物生长。 |
| **Yield** | 产量 | 单位面积或一次生产中获得的食物数量。 |
| **Productivity** | 生产率 | 用一定土地、时间、劳动或资源生产食物的效率。 |
| **Staple Crop** | 主粮作物 | 为许多人提供主要能量的基础作物，例如水稻、小麦和玉米。 |
| **Green Revolution** | 绿色革命 | 20世纪通过新品种、化肥、灌溉和管理提高粮食产量的农业变化。 |
| **Semi-Dwarf Variety** | 半矮秆品种 | 较矮、抗倒伏、能把更多能量用于籽粒的作物品种。 |
| **Fertilizer** | 肥料 | 为植物提供氮、磷、钾等营养的物质。 |
| **Mechanization** | 机械化 | 使用机器代替或辅助人力、畜力完成农业工作。 |
| **Monoculture** | 单一种植 | 大面积种植同一种作物的生产方式。 |
| **Biodiversity** | 生物多样性 | 一个生态系统中不同生物种类和遗传差异的丰富程度。 |
| **Tradeoff** | 取舍 | 提高产量、效率或便利性时可能带来的环境、成本或风险代价。 |

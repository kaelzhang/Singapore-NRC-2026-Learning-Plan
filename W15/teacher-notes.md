# W15 Teacher Notes

## Aim
Students should stop using "it worked once" as proof. They should learn evidence-based iteration.

## Pacing
- 10 min: Demonstrate one lucky run versus repeated runs.
- 20 min: Explain variable, control, failure mode, root cause.
- 30 min: 5-run or 10-run table practice.
- 20 min: Failure mode classification.
- 10 min: Evidence-based claim writing.

## Misconceptions To Watch
- "Testing is what we do after building." Testing is part of building.
- "Changing many things is faster." It hides the cause.
- "Failure is bad." Unrecorded failure is bad; recorded failure is useful.

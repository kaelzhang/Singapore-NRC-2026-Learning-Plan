# W09 Teacher Notes

## Aim
Students should learn that object handling is a design problem, not an afterthought.

## Pacing
- 10 min: Show three different objects and ask how to move each.
- 20 min: Explain end-effectors, levers, gears, torque, and compliance.
- 25 min: Paper prototype three tools.
- 25 min: Quick-change interface sketch.
- 10 min: Design rule share-out.

## Misconceptions To Watch
- "One gripper can handle everything." Different objects need different tools.
- "Stronger is always better." Delicate objects need controlled force.
- "Long arms are always useful." Long tools can reduce precision and increase wobble.

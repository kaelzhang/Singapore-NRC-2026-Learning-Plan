# W09 - End-Effectors, Grippers, Levers, Gears, And Modular Tools Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**End-Effector**, **Gripper**, **Lever**, **Pivot**, **Gear Ratio**, **Torque**, **Mechanical Advantage**, **Compliance**, **Contact Area**, **Friction**, **Centre Of Mass**, **Degree Of Freedom**, **Passive Tool**, **Modular Interface**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **End-Effector** | 末端执行器 | 机器人最前端接触并处理物体的工具。 |
| **Gripper** | 夹爪 | 用来夹住或握住物体的末端工具。 |
| **Lever** | 杠杆 | 绕支点转动、改变力和距离关系的刚性结构。 |
| **Pivot** | 支点 | 杠杆或部件旋转围绕的点。 |
| **Gear Ratio** | 齿轮比 | 两个齿轮转动速度和扭矩关系的比例。 |
| **Torque** | 扭矩 | 让物体转动的力矩。 |
| **Mechanical Advantage** | 机械优势 | 用机构让较小输入力产生较大输出力的效果。 |
| **Compliance** | 柔顺性 | 工具能稍微变形或让位以适应物体的能力。 |
| **Contact Area** | 接触面积 | 工具和物体接触的表面大小。 |
| **Friction** | 摩擦力 | 两个表面相互阻止滑动的力。 |
| **Centre Of Mass** | 质心 | 物体重量可以看作集中所在的位置。 |
| **Degree Of Freedom** | 自由度 | 机构可以独立运动的方向或方式数量。 |
| **Passive Tool** | 被动工具 | 不需要单独马达也能通过形状完成任务的工具。 |
| **Modular Interface** | 模块接口 | 让不同工具可以快速连接和更换的结构。 |

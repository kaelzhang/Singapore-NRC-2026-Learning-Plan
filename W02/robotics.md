# W02 Robotics - Singapore's Food Story And Urban Food Resilience

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
Singapore's food system gives many robot mission ideas:

- a robot moves crates from import dock to storage,
- a robot checks a local farm row,
- a robot sorts local produce,
- a robot delivers seafood to a cold storage zone,
- a robot uses a tool to collect eggs or vegetables without damage.

Try this translation:

```text
Limited land -> high-density growing -> robot must move carefully in narrow spaces
```

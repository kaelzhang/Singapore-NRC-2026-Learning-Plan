# W02 - Singapore's Food Story And Urban Food Resilience Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**Food Resilience**, **Import Diversification**, **Local Production**, **Buffer**, **Stockpiling**, **Global Partnership**, **Urban Food Resilience**, **Fibre**, **Protein**, **Novel Food**, **Aquaculture**, **Controlled Environment**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **Food Resilience** | 食物韧性 | 城市或国家在供应受影响时仍能保障食物的能力。 |
| **Import Diversification** | 进口多元化 | 从多个国家或来源获得食物，降低依赖单一来源的风险。 |
| **Local Production** | 本地生产 | 在本地种植、养殖或制造一部分食物。 |
| **Buffer** | 缓冲 | 用来吸收冲击的备用能力、时间或资源。 |
| **Stockpiling** | 储备 | 提前保存关键食物或物资，以便短缺时使用。 |
| **Global Partnership** | 全球伙伴关系 | 通过国际合作保障贸易、供应、技术和食物安全。 |
| **Urban Food Resilience** | 城市食物韧性 | 高密度城市在土地有限和进口依赖下维持食物供应的能力。 |
| **Fibre** | 膳食纤维 | 蔬菜、水果和谷物中的重要成分，帮助消化和健康饮食。 |
| **Protein** | 蛋白质 | 身体生长、修复和维持肌肉、器官的重要营养物质。 |
| **Novel Food** | 新食品 | 没有长期食用历史、需要额外安全评估的新型食物或成分。 |
| **Aquaculture** | 水产养殖 | 人工养殖鱼、虾、贝类或水生植物的食物生产方式。 |
| **Controlled Environment** | 受控环境 | 人为管理温度、光照、水分、空气和营养的生产空间。 |

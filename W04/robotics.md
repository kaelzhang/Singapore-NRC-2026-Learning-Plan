# W04 Robotics - Food Security Today: Hunger, Nutrition, Affordability, And Productivity

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
A robot can support food security only when its task is clear:

- improve production,
- reduce damage,
- move food faster,
- sort food more accurately,
- check storage conditions,
- reduce waste,
- collect data for decisions.

When you design, add this sentence:

```text
This robot task supports food security by improving [availability/access/utilization/stability].
```

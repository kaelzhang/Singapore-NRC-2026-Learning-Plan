# W04 - Food Security Today: Hunger, Nutrition, Affordability, And Productivity Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**Hunger**, **Food Insecurity**, **Malnutrition**, **Undernutrition**, **Micronutrient**, **Healthy Diet**, **Affordability**, **Productivity**, **Supply Shock**, **Early-Warning System**, **Food Price Inflation**, **Social Protection**, **Food Utilization**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **Hunger** | 饥饿 | 身体没有获得足够食物能量的状态。 |
| **Food Insecurity** | 食物不安全 | 获得食物变得不确定、困难或不稳定的情况。 |
| **Malnutrition** | 营养不良 | 食物数量或营养成分不合适导致的健康问题。 |
| **Undernutrition** | 营养不足 | 长期摄入能量、蛋白质或关键营养素不足。 |
| **Micronutrient** | 微量营养素 | 身体需要量很小但非常重要的维生素和矿物质。 |
| **Healthy Diet** | 健康饮食 | 能提供能量、蛋白质、纤维、维生素和矿物质的均衡饮食。 |
| **Affordability** | 可负担性 | 人们是否有能力用合理成本买到所需食物。 |
| **Productivity** | 生产率 | 用一定资源生产食物的效率。 |
| **Supply Shock** | 供应冲击 | 突然减少食物供应或扰乱运输、价格的事件。 |
| **Early-Warning System** | 预警系统 | 提前发现风险并提醒人们采取行动的系统。 |
| **Food Price Inflation** | 食品价格通胀 | 食物价格持续上涨，使家庭更难购买食物。 |
| **Social Protection** | 社会保障 | 帮助家庭应对困难的政策或支持，例如补贴、餐食或现金援助。 |
| **Food Utilization** | 食物利用 | 食物是否安全、营养适合，并能被身体有效吸收和使用。 |

# W07 - Precision Agriculture, Sensors, Drones, And Data Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**Precision Agriculture**, **Sensor**, **GPS**, **GNSS**, **Remote Sensing**, **Multispectral Imaging**, **Vegetation Index**, **NDVI**, **Variable Rate Application**, **Computer Vision**, **Machine Learning**, **Data Quality**, **Calibration**, **Targeted Action**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **Precision Agriculture** | 精准农业 | 根据不同地点或作物状态精准决定行动的农业方式。 |
| **Sensor** | 传感器 | 测量光、颜色、距离、温度、湿度等信息的装置。 |
| **GPS** | 全球定位系统 | 利用卫星帮助确定位置的系统。 |
| **GNSS** | 全球卫星导航系统 | 包括GPS等多种卫星定位系统的总称。 |
| **Remote Sensing** | 遥感 | 不用直接接触目标就收集信息的方法。 |
| **Multispectral Imaging** | 多光谱成像 | 用多个波段观察作物或地表状态的成像方法。 |
| **Vegetation Index** | 植被指数 | 用光谱数据计算植物健康或覆盖情况的指标。 |
| **NDVI** | 归一化植被指数 | 常用红光和近红外光判断植物活力的指数。 |
| **Variable Rate Application** | 变量施用 | 根据不同区域需要改变水、肥料或药剂用量。 |
| **Computer Vision** | 计算机视觉 | 让计算机从图像中识别物体、形状或状态。 |
| **Machine Learning** | 机器学习 | 让计算机从例子中学习模式并做出判断。 |
| **Data Quality** | 数据质量 | 数据是否准确、完整、稳定并适合用来决策。 |
| **Calibration** | 校准 | 把测量工具调整到可靠读数的过程。 |
| **Targeted Action** | 定向行动 | 只在需要的位置或对象上采取行动。 |

# W07 Robotics - Precision Agriculture, Sensors, Drones, And Data

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
This week connects directly to sensors and autonomous behaviour:

- a colour sensor detects a marked crop zone,
- a robot changes action based on marker colour,
- a robot counts objects,
- a robot follows a map,
- a robot records success or failure.

NRC translation:

```text
Precision farming -> sense before acting
Weed targeting -> act only on selected objects
Field map -> robot route plan
```

## Build And Programming Tasks
1. Draw a field with four zones: dry, healthy, weedy, and ready to harvest.
2. Choose one sensor for each zone.
3. Write one decision rule using "if...then..."
4. Translate one decision rule into Scratch-style pseudocode.
5. Identify one way the sensor could be wrong.

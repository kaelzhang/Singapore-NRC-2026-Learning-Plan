# W07 - Precision Agriculture, Sensors, Drones, And Data

## Big Question
How can farmers know exactly where a crop needs water, nutrients, or protection?

## Why This Week Matters
Precision agriculture is about making better decisions by observing differences. A field is not the same everywhere. One area may be dry, another may have weeds, and another may need nutrients.

Robots also need this idea. A good robot does not act blindly. It senses, decides, then acts.

## The One-Minute Idea
Precision agriculture uses sensors, maps, GPS, drones, cameras, satellites, and data to treat different places differently. The goal is to use the right input, in the right place, at the right time.

For an eight-year-old: instead of giving every plant the same help, precision agriculture asks, "What does this plant or place need?"

## Past, Present, Future
### Past
Farmers have always observed differences by walking fields, touching soil, watching leaves, and remembering seasons. The old tool was human experience.

### Present
Modern farms can collect data using soil sensors, weather stations, GPS tractors, drones, satellite images, cameras, and yield maps. Machines such as smart sprayers can use computer vision to target weeds instead of spraying everything.

### Future
Future precision agriculture may combine robots, AI, plant-level sensing, autonomous tractors, early disease detection, and data platforms. The challenge is to make these systems accurate, affordable, repairable, and fair for farms of different sizes.

## Deep Explanation
### 1. Fields Are Variable
A field may look like one big rectangle, but it contains many micro-conditions. Soil type, slope, shade, pests, moisture, and nutrients can vary from one spot to another.

If farmers treat the whole field the same, some areas may get too much input while others get too little.

### 2. Sensors Turn Conditions Into Data
A sensor measures something. A soil moisture sensor measures water level. A camera measures reflected light. A weather station measures temperature, rain, wind, and humidity.

Data is useful only if it leads to a decision.

```text
measure -> compare -> decide -> act -> check result
```

### 3. Remote Sensing Looks From Above
Remote sensing means collecting information without touching the target. Satellites and drones can see crop patterns from above. Multispectral cameras can capture light beyond normal human vision, which can reveal plant stress.

### 4. Variable Rate Application Changes The Amount
Variable rate application means using different amounts of water, fertilizer, seed, or pesticide in different places. This can reduce waste and pollution, but only if the data and equipment are accurate.

### 5. Data Has Limits
Bad data can lead to bad decisions. Sensors can fail. Cameras can be confused by shadows. Algorithms can be biased toward farms that can afford expensive tools.

Precision agriculture is powerful, but it must be tested.

## Core Terms
### Precision Agriculture
Farm management that uses data to observe, measure, and respond to differences in fields, crops, or animals.

### Sensor
A device that measures something in the world.

### GPS
A satellite-based system that helps locate a position on Earth.

### Remote Sensing
Collecting information from a distance, often using satellites, drones, or cameras.

### Multispectral Imaging
Using cameras that see several bands of light, including light humans cannot see.

### Variable Rate Application
Applying different amounts of input in different places.

### Computer Vision
A technology that helps computers interpret images.

### Data Quality
How accurate, reliable, complete, and useful data is for making decisions.

## Robot Connection
This week connects directly to sensors and autonomous behaviour:

- a colour sensor detects a marked crop zone,
- a robot changes action based on marker colour,
- a robot counts objects,
- a robot follows a map,
- a robot records success or failure.

NRC translation:

```text

Weed targeting -> act only on selected objects
Field map -> robot route plan
```

This student document turns the week's science into robot building, mechanism, programming, testing, or mission-design work. Read `science.md` first.

## Robotics Focus
CEA is a natural robotics environment because it has structured rows, trays, markers, and repeated tasks.

Possible robot tasks:

- visit each growing rack,
- move seedling trays,
- deliver a nutrient token,
- sort harvested vegetables,
- check colour markers,
- carry a crate from growth area to packing area.

NRC translation:

```text
Stacked farm -> narrow robot paths
Sensor station -> robot stops at markers
Tray movement -> robot uses a pusher or lifter
```

# W06 - Controlled Environment Agriculture, Hydroponics, And Vertical Farms Keyword Index

This document is a quick review index for the science reading in this week. It lists the core keywords, Chinese explanations, and the concrete meaning of each term.

## 当前所有关键字

**Controlled Environment Agriculture**, **Greenhouse**, **Plant Factory**, **Vertical Farming**, **Hydroponics**, **Aeroponics**, **Aquaponics**, **Root Zone**, **Light Recipe**, **Climate Control**, **Biosecurity**, **Recirculation**, **Energy Efficiency**, **Tradeoff**

## 关键词解释

| Keyword | 中文解释 | 具体含义 |
| --- | --- | --- |
| **Controlled Environment Agriculture** | 受控环境农业 | 在人工控制的空间中种植作物的农业方式。 |
| **Greenhouse** | 温室 | 用结构和覆盖材料调节光、热和环境的种植空间。 |
| **Plant Factory** | 植物工厂 | 高度控制光照、温度、水分和营养的室内种植系统。 |
| **Vertical Farming** | 垂直农场 | 把植物分层种植以节省水平土地的生产方式。 |
| **Hydroponics** | 水培 | 用营养液而不是土壤供给植物根部。 |
| **Aeroponics** | 雾培 | 让根部悬空并用雾状营养液供给植物。 |
| **Aquaponics** | 鱼菜共生 | 把水产养殖和植物种植连接起来循环利用养分。 |
| **Root Zone** | 根区 | 植物根部所在并吸收水分和营养的区域。 |
| **Light Recipe** | 光配方 | 为作物设置的光颜色、强度和时间组合。 |
| **Climate Control** | 气候控制 | 管理温度、湿度、空气流动和二氧化碳等条件。 |
| **Biosecurity** | 生物安全 | 防止病虫害或污染进入生产系统的措施。 |
| **Recirculation** | 循环利用 | 让水或营养液在系统中重复使用。 |
| **Energy Efficiency** | 能源效率 | 用更少能源完成同样生产目标的能力。 |
| **Tradeoff** | 取舍 | 更多控制可能带来更高成本、能耗或维护要求。 |
